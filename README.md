# Ambient OS: Animus 4.0 Nexus

**Description:** A high-performance AI system for psytrance producers and DJs, featuring set planning, visual generation, and crowd analysis.

## Overview

Ambient OS is a specialized, dark-cybernetic AI telemetry platform engineered for psytrance producers, DJs, and sound architects. It integrates deep machine intelligence, real-time audio pipeline resolution, and autonomous service coordination to visualize and plan complex sonic structures and "genetic sets."

## Design Vision & Aesthetic

Ambient OS utilizes an immersive **Cosmic Slate Theme** with high-contrast neural-blue and emerald-green accents, designed for low-light performance environments and high-speed telemetry monitoring.

## Features

*   **Sonic Structure Planning:** AI-assisted arrangement and planning for complex psytrance sets.
*   **Real-Time Visual Generation:** Dynamic, audio-reactive visuals generated on the fly.
*   **Crowd & Telemetry Analysis:** Real-time feedback loops for performance optimization.
*   **Cybernetic Interface:** Engineered for rapid situational awareness and creative flow.

## Getting Started

### Prerequisites

*   Node.js

### Local Development

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Run the application:**
    ```bash
    npm run dev
    ```
